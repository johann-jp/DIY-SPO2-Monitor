# DIY SpO₂ Monitor

A custom PCB designed in **KiCad 10** for a portable Arduino Nano-based pulse oximeter. This project uses the **MAX30102** optical sensor to measure blood oxygen saturation (SpO₂) and heart rate, displaying the readings on an **SSD1306 OLED** display.

---

## Features

- Real-time SpO₂ monitoring
- Heart rate measurement
- SSD1306 OLED display
- Menu navigation using push buttons
- Alarm LED/Buzzer indication
- Arduino Nano based
- Custom PCB designed in KiCad 10

---

## Hardware Used

- Arduino Nano
- MAX30102 Pulse Oximeter Sensor
- SSD1306 OLED Display (I2C)
- Push Buttons
- LED/Buzzer
- Resistors
- Capacitors
